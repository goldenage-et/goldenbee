# Issue tracker

Public issue tracking is not open yet. When it is enabled, GitHub Issues will
be the tracker.

## Planned conventions

- Use one issue per independently reviewable change.
- Describe the problem, the affected component, and the observable acceptance
  criteria.
- Link related pull requests and architecture decisions.
- Keep credentials, personal data, and local filesystem paths out of issues.

## Triage

Resolve labels through `docs/agents/labels.md`. Do not close a security report
in public; follow `SECURITY.md`.
