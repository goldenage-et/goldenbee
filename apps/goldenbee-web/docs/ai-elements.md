# Vendored shadcn/ui and AI Elements components

## Source and version

- Documentation: <https://ui.shadcn.com/docs/ai-elements>
- CLI: `shadcn@4.23.0` (recorded as `^4.23.0` in `package.json`)
- Style: `base-rhea` (`components.json`), Tailwind CSS v4, Base UI primitives,
  Lucide icons, Inter variable font
- Vendored: 2026-11-21

The new shadcn AI Elements replace the deprecated <https://elements.ai-sdk.dev>
project. AI Elements now have no runtime package: the reusable components are
copied into `src/components/ui` from the shadcn registry, and patterns are
compositions of those components. This app vendors the components, not the
demo compositions that use AI SDK transports.

## Commands used

```bash
npx shadcn@latest init -b base -p rhea
npx shadcn@latest add button card input label badge alert separator tooltip \
  spinner empty field input-group message bubble message-scroller trace \
  collapsible attachment code-block scroll-area checkbox
npx shadcn@latest add table dialog
```

## Rules

- Keep Gateway-specific mapping in feature wrappers, not in vendored files.
- Do not add AI SDK, TanStack AI, or AI Elements helper transports. The app
  consumes typed Gateway stream events through its own SDK and reducer.
- Re-running the shadcn CLI may rewrite vendored files. Review the diff and
  keep the source record current.
